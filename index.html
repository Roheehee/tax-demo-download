安卓网页版安装

使用 Chrome 添加到主屏幕，目前不提供 APK。

苹果安装步骤

  1. 用 Safari 打开本页，点上方“安装苹果”。
  2. 手机询问是否下载描述文件时，选择“允许”。
  3. 打开手机“设置 → 已下载描述文件”，核对“个税演示 · 桌面图标”，按提示点“安装”。
  4. 回到桌面，打开“个税演示”。首次请保持联网。

若设置首页没有入口，可在“通用 → VPN与设备管理”查看。下载后请及时安装；超时失效可重新下载。

安装的是什么？

苹果版安装后会添加一个全屏网页的桌面入口，无需 ChatGPT 登录，也不用每周重新签名。

这是未签名的桌面图标描述文件，不是 IPA。它只包含一个网页入口，不设置设备管理、VPN、证书或账号；安装时可能显示“未签名”。可在设置中移除。

应用为脱敏比赛演示，数据保存在当前设备。旧入口数据需先导出 JSON，再导入并核对。
